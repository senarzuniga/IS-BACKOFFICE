1. Executive Summary

This document presents INGECART’s executive business case and economic proposal framework for the relocation of the BHS corrugator line to PSC Visalia, together with the recommended industrial roadmap for subsequent automation phases.

The project has been analyzed under a scenario-based approach to balance three critical objectives: rapid industrial start-up, capital deployment discipline and future productivity optimization potential. The analysis therefore distinguishes between the immediate relocation and commissioning scope required to bring the plant back to production as quickly as possible, and the additional investment layers that can further improve logistics efficiency, WIP flow, machine-side performance and long-term operating leverage.

Under this framework, Scenario A is positioned as the base implementation package, combining the corrugator relocation scope, the INGETRANS reel logistics backbone, the required project peripherals and PSC’s local implementation items. Scenario B adds AMR intralogistics as a second automation layer to optimize internal flows and create a scalable platform for future plant-wide logistics automation. Scenario C adds the Triplex package to strengthen machine-side process capability and further enhance production performance once the relocated line is stabilized.

INGECART recommendation. From a time-to-market and execution-risk standpoint, INGECART recommends using Scenario A as the immediate implementation baseline, while keeping Scenario B (AMR intralogistics) and Scenario C (Triplex) as structured follow-on phases aligned with PSC’s production ramp-up priorities and investment timing.

2. Economic Summary

2.1 Project Economic Scenarios Evaluated

INGECART has evaluated three implementation scenarios for the PSC Visalia corrugator relocation project. The purpose of this scenario-based approach is to balance time-to-market, initial capital deployment, operational continuity and future productivity optimization potential.

Scenario A – Base Industrial Relocation Package
Scenario A represents the recommended base implementation to secure the relocation and commissioning of the corrugator line within the shortest possible timeframe, while integrating the core logistics and production systems required for a stable industrial start-up. This scenario includes the corrugator line relocation package, the INGETRANS automated reel logistics system, the project peripherals, PSC associated local implementation costs and the additional execution-related estimated items required to complete the project.

Scenario B – Scenario A + AMR Intralogistics
Scenario B builds on Scenario A by incorporating the AMR intralogistics layer. This phase extends the automation scope beyond reel logistics into internal plant flow management, enabling flexible WIP transportation, automated load movements between process islands and a scalable architecture for future waste-handling automation.

Scenario C – Scenario A + Triplex
Scenario C builds on Scenario A by adding the Triplex package. This scenario is intended to strengthen corrugator process capability and support higher production performance through additional machine-side technical upgrades and associated installation scope.

2.4 Executive Interpretation of the Scenarios

From a project execution standpoint, Scenario A is the most balanced solution to accelerate production restart and protect time-to-market, while still integrating the core automation backbone through INGETRANS and the required peripheral systems.

Scenario B should be understood as the next logical automation step for internal plant flow optimization. By adding AMR intralogistics, PSC would gain a flexible platform for WIP flow automation between process islands, reduction of manual internal handling, future traceable waste logistics and scalable internal transport orchestration without depending on fixed conveyor infrastructure.

Scenario C represents a process-capability upgrade route through the Triplex package, with the potential to strengthen machine-side performance and overall corrugator process efficiency once the relocated plant is fully stabilized.

3. Commercial and Scope Clarifications

The economic structure presented in this proposal reflects the progressive refinement of the project definition as additional technical, logistical and execution-related details have been confirmed during the analysis process. As the project evolved from an initial relocation estimate into a more complete industrial implementation assessment, several cost items required clearer separation and more precise allocation in order to reflect the real execution conditions of the PSC project.

In particular, the final structure distinguishes between: (i) the core machine relocation package, (ii) the production and logistics systems directly supplied within the INGECART scope, (iii) PSC’s local implementation items and (iv) the execution-related estimated allowances associated with import duties, transport/packaging and crane services. This approach improves transparency, avoids double counting between commercial blocks and provides PSC with a clearer view of which items belong to the direct supply scope and which should be treated as execution-side project allowances.

In the same way, the optional project management support and the future automation phases are intentionally shown as separate decision layers. This allows PSC to prioritize the immediate production restart and time-to-market objective, while preserving a clear roadmap for subsequent productivity, flexibility and plant efficiency improvements.
