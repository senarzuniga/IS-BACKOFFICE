🔍 Perfiles de Competidores

🔷 KUKA.AMR Fleet

  • Empresa: KUKA SE (Augsburg) / Midea Group
  • Fortaleza: Flotas heterogéneas, VDA5050 nativo, no-code, casos industriales verificados
  • Limitación: Vendor lock parcial (hardware KUKA preferred), coste premium
  • Mejor para: Producción industrial pesada, automotive, intralogística compleja
  • Pricing: Licencia + hardware. €150K-500K proyecto completo
  • Veredicto: REFERENCIA TÉCNICA

🔶 MiRFleet (Mobile Industrial Robots / Teradyne)

  • Empresa: MiR (Odense) / Teradyne
  • Fortaleza: Facilidad de uso, amplia base instalada, buena documentación
  • Limitación: Optimizado para robots MiR, interop limitada con otros fabricantes
  • Mejor para: Flotas homogéneas MiR en logística interna
  • Pricing: Software incluido con robots MiR
  • Veredicto: ALTERNATIVA SIMPLE

🟢 Geek+ RMS

  • Empresa: Geek+ (Beijing)
  • Fortaleza: Escala masiva (10K+ robots), e-commerce especializado
  • Limitación: Ecosistema cerrado, foco e-commerce no producción
  • Mejor para: Almacenes de alta rotación, e-commerce
  • Pricing: SaaS subscription + hardware
  • Veredicto: NO APLICABLE CORRUGADO

🟡 InOrbit.AI

  • Empresa: InOrbit Inc. (Mountain View)
  • Fortaleza: Observabilidad, analytics avanzados, multi-vendor nativo
  • Limitación: Es una capa de monitoring/analytics, no un WCS completo
  • Mejor para: Overlay analytics sobre flota existente
  • Pricing: SaaS, ~€500-2000/robot/año
  • Veredicto: COMPLEMENTARIO

⚪ OpenRMF (OSRF)

  • Empresa: Open Source Robotics Foundation
  • Fortaleza: Open source, máxima flexibilidad, vendor-free
  • Limitación: Requiere expertise ROS2 elevado, comunidad pequeña en producción industrial
  • Mejor para: Proyectos de I+D, prototipos, entornos controlados
  • Pricing: Gratuito (open source)
  • Veredicto: BASE ARQUITECTURAL

🌐 ING_DIGHUB FMS (Propuesto)

  • Empresa: INGECART / ING_DIGHUB
  • Fortaleza: Integración nativa Knowledge Hub, especializado cartón corrugado, VDA5050 nativo, Knowledge Graph
  • Limitación: En desarrollo, requiere inversión inicial
  • Mejor para: Plantas de cartón corrugado con múltiples convertidoras
  • Pricing: Inversión interna + licencia para terceros
  • Veredicto: OBJETIVO ESTRATÉGICO
🎯 Recomendación Estratégica

Conclusión del Benchmark para ING_DIGHUB

Estrategia recomendada: KUKA como referencia funcional + OpenRMF como referencia arquitectural + desarrollo interno ING_DIGHUB FMS especializado.

Fase 1 (0-12 meses): Implementar KUKA.AMR Fleet en el proyecto piloto INGECART. Aprender de la experiencia real. Documentar gaps entre KUKA.AMR Fleet y los requisitos específicos de cartón corrugado.

Fase 2 (12-24 meses): Desarrollar ING_DIGHUB FMS como wrapper/extensión sobre KUKA.AMR Fleet o como sistema paralelo. Añadir Knowledge Graph, corrugated-specific intelligence, y Digital Twin avanzado.

Fase 3 (24+ meses): ING_DIGHUB FMS como producto propio, replicable a otras plantas corrugado. Potencial de licenciamiento a terceros.
