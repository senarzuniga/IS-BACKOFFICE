Design Rules — Accessibility Constraints

🚫 Forbidden Combinations

  • Gray text on gray background (fails AA)
  • White text on yellow (fails AA)
  • Gray text on dark blue (low contrast)
  • Disabled-weight text on dark surfaces
  • Placeholder text lighter than --text-disabled

✅ Required Minimums

  • Normal text: ≥ 4.5:1 (WCAG AA)
  • Large text (>18pt): ≥ 3:1
  • UI components/icons: ≥ 3:1
  • Focus rings: visible, ≥ 3:1
  • All interactive states: hover, focus, active

📋 Implementation Rules

  • NEVER hardcode hex colors in pages
  • ALWAYS use CSS variable tokens
  • Call inject_theme() in every page main()
  • HTML reports: exempt (printed docs)
  • Theme variants: INDUSTRIAL (default), DARK, LIGHT

🏭 Industrial Identity

  • Background: Deep black #0D0F13
  • Surfaces: Dark grays, no teal/green/blue
  • Accent: Orange only #FF6A00
  • Typography: Clean, high-weight labels
  • NO gradients on solid backgrounds
