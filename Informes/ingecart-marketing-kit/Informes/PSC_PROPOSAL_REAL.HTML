1. Executive Summary

The PSC Visalia project is not only a machine relocation exercise. It is a production continuity and time-to-market project whose real objective is to bring the future plant to full operating condition as fast and as safely as possible, while preserving the option to unlock additional productivity and automation gains in subsequent phases.

Following the latest engineering and commercial review, the project structure has been reorganised into a clearer decision framework with three purposes:

  • Separate the core start-up scope required to relocate and commission the corrugator successfully from the optional productivity phases that can be executed later.
  • Reflect the actual industrial architecture of the project, including machine relocation, required peripherals, INGETRANS integration logic, and PSC-side associated costs.
  • Present PSC with a phased investment roadmap where time-to-market is protected first, while future performance upgrades remain fully visible and economically assessable.

Executive positioning of the revised proposal

The updated proposal should not be read as a correction of a simple commercial list. It reflects the evolution of the project definition as engineering discussions, logistics assumptions, equipment origin, site integration constraints and customs/import implications have become clearer. As the project moved from an early budgetary structure into a more operationally grounded proposal, several cost blocks needed to be isolated and represented in a way that is more consistent with actual execution responsibility.

What Scenario A now represents

Scenario A is now the reference implementation path for launching the new PSC corrugator operation with the correct industrial basis: machine relocation, essential project peripherals, PSC associated local costs, INGETRANS integration, and the additional logistics/import allowances required to make the execution budget coherent with the final project structure.

How future phases are treated

The Triplex package and the AMR intralogistics package remain highly relevant for long-term performance, but they can be positioned as follow-on phases in order to protect start-up speed, reduce initial execution complexity, and minimise disruption once the plant is already producing.

2. Why the Project Structure Has Evolved

During the development of the offer, the project moved from a preliminary relocation concept into a more mature industrial integration scenario. That transition has direct consequences on how the commercial structure must be presented to PSC.

2.1 Key reasons behind the revised project presentation

Adjustment area Executive rationale
Machine relocation baseline clarified The relocation block has been restated using the latest validated structure for dismantling, transport, packaging, installation, engineering and upgrade-related works, so the core machine scope is shown with greater execution clarity.
Project management separated as an optional support layer The 8-month on-site project management support is shown independently as an optional relocation support service, allowing PSC to distinguish between the pure relocation price and the additional execution support layer that may be deployed depending on the final governance model.
Peripheral systems isolated as a dedicated project block Adhesive kitchen, glue and steam distribution, and exit conveyor systems have been grouped as a standalone block because they are essential to industrial readiness, but conceptually different from the relocated corrugator itself.
PSC associated local costs made explicit Boiler and civil works remain PSC-side enabling costs. Presenting them explicitly improves budget transparency and avoids mixing INGECART supply scope with local plant adaptation scope.
Import duties, logistics and handling allowances surfaced separately Fees, import taxes, transport packaging allowances and crane assumptions are now shown as dedicated consideration items where applicable, because they materially affect the total delivered project cost and are driven by the final sourcing / shipping structure rather than by the mechanical scope alone.
Automation phases decoupled from immediate start-up priority Triplex and AMR intralogistics have significant productivity potential, but they can be staged after start-up to reduce implementation risk and preserve the fastest route to production.
In commercial terms, this is the key message to PSC: the proposal has been refined to better match the real execution model of the project. It is not a cosmetic repricing exercise; it is the consequence of progressively aligning engineering scope, import exposure, site responsibilities and phased industrial priorities.

3. Scenario Architecture

The project can now be discussed with PSC through a structured scenario logic. This is useful because it separates the minimum industrial path required to start the plant from the future performance layers that may be added once the operation is stabilised.

Scenario A — Core Relocation & Start-up Platform Reference delivery path

Scenario A is the base industrial execution package. It combines the machine relocation, the essential project peripherals, PSC associated enabling costs, the INGETRANS solution and the additional import / logistics allowances already identified for this scope.

  • Machine relocation package
  • Project peripherals package
  • PSC associated local items
  • INGETRANS system
  • Additional fees / import taxes estimation
  • Additional transport & packaging estimation
  • Additional cranes rental estimation

Strategic role of Scenario A: provide the fastest credible route to bring the plant into production with the correct mechanical, utility and logistics backbone already embedded.

Scenario B — Scenario A + Triplex Productivity Upgrade Recommended industrial path

Scenario B builds on Scenario A and adds the Triplex package. This phase is not only an equipment add-on; it is a productivity reinforcement layer that can improve the corrugator’s operating envelope, support higher production stability, and strengthen the medium-term throughput capability of the plant.

  • Includes all Scenario A scope
  • Adds Triplex equipment package and associated integration works
  • Adds the additional import duties / fees specifically linked to the Triplex block

Strategic role of Scenario B: combine rapid plant activation with a stronger productivity architecture from day one or from a closely sequenced follow-on phase.

Scenario C — Scenario A + AMR Intralogistics Future automation phase

Scenario C keeps the same core base as Scenario A and adds the AMR intralogistics package. This is the scenario that begins to transform internal material flow, operator dependency and future waste-control capability at plant level.

  • Includes all Scenario A scope
  • Adds AMR intralogistics package
  • Adds the additional import duties / fees specifically linked to the AMR block

Strategic role of Scenario C: turn the relocation project into the first step of a broader digital intralogistics architecture capable of supporting WIP handling, internal flow control and a future waste-management automation layer.

INGECART recommendation on scenario logic

If PSC’s priority is to protect time-to-market while still preserving the industrial logic required for a high-performance plant, INGECART recommends using Scenario A as the execution baseline and Scenario B as the preferred strategic target.

In practical terms, our recommendation is:

  • Use Scenario A as the minimum validated implementation platform for start-up.
  • Position Scenario B as the preferred productivity route because it improves the long-term performance architecture of the corrugator line without changing the fundamental execution logic of the base project.
  • Position Scenario C as the plant-wide automation step that should follow once the operation is stabilised and PSC wants to extend control over internal flow, labour dependency and future waste-management processes.

4. Industrial Value of INGETRANS in the Base Project

One of the most important strategic decisions in the revised structure is that INGETRANS is already included in Scenario A. This is relevant because it means the base project is not just a machine move; it already incorporates a logistics and flow-control component designed to improve how reels are supplied and managed around the corrugator.

1. Reel flow continuity

INGETRANS reduces dependence on ad-hoc forklift supply patterns and creates a more predictable and synchronised reel-feeding process, supporting better production continuity at the corrugator.

2. Lower logistics disruption

By structuring the flow of reels around the machine more efficiently, INGETRANS contributes to lower congestion, fewer handling conflicts, and a cleaner operating environment in one of the most sensitive zones of the plant.

3. Better platform for future automation

Integrating INGETRANS in the base scenario creates a stronger platform for future AMR intralogistics phases because the plant flow is already being organised around a more structured internal logistics model.

4.1 Indicative performance logic associated with INGETRANS

Based on prior corrugated logistics benchmarks and INGECART’s digital twin logic for automated reel supply, the value of INGETRANS is typically expressed through:

  • Higher reel availability at the corrugator interface
  • Lower risk of logistics-induced waiting time
  • Reduced forklift traffic concentration around the line
  • More stable reel replenishment cycles
  • Lower exposure to manual handling variability

Exact performance values must be calibrated against PSC production data, reel consumption patterns, staffing model and final plant layout. For that reason, this proposal frames the benefit as an industrial performance lever rather than as a guaranteed single-number saving.

5. Role of Triplex and AMR as Future Value Layers

5.1 Triplex as a productivity expansion phase

The Triplex package should be understood as a corrugator productivity and capability enhancement block. While it is not required to start the plant, it can materially improve the machine’s medium-term operating envelope by upgrading the line architecture around key paper handling and process functions.

Why Triplex matters strategically

  • Improves the production platform beyond simple relocation.
  • Supports a stronger long-term productivity ratio once the plant is stabilised.
  • Can be executed as a follow-on industrial phase if PSC wants to protect immediate time-to-market first.

5.2 AMR intralogistics as the future backbone of plant efficiency

The AMR package should be positioned as the catalyst of the next automation layer for PSC. Its role is broader than transport: it becomes the organising backbone for internal material movement, route discipline, WIP flow support and future traceable waste handling logic.

AMR value in a future phase

  • Structured internal movement of materials and WIP between defined production points.
  • Lower manual transport dependency in repetitive internal routes.
  • Potential reduction in handling-related waste through more controlled movements.
  • Stronger traceability logic for “in” and “out” material flows.

Optional waste-flow application

As a non-valued optional extension, the same AMR fleet can later be used for internal waste collection from corrugator and converting positions, using metallic cages as transport containers. AMRs can collect, weigh and relocate these containers to the required destination points, creating a structured basis for internal scrap traceability and waste-flow discipline.

7. Business-Case Logic and Indicative ROI View

At this stage, the economic discussion with PSC should be framed around three different value layers, not around a single simplistic payback number:

Layer 1
Time-to-market
How quickly PSC can restore full production capability in Visalia
Layer 2
Productivity platform
How the chosen architecture improves throughput stability and operational discipline
Layer 3
Future efficiency
How Triplex and AMR can unlock additional value after stabilisation
Commercial lens
Phased investment
Protect start-up now; add performance blocks when the plant is ready

7.1 Scenario A ROI logic

Scenario A should not be judged only as a cost package; it is the price of bringing the new plant into production with the correct industrial backbone. Its economic return is therefore primarily linked to:

  • Avoiding delays in production start-up.
  • Reducing the risk of under-designed integration during commissioning.
  • Embedding INGETRANS from the beginning instead of retrofitting the core reel logistics architecture later.
  • Creating a plant layout and execution basis that supports future productivity phases without having to re-open the core relocation logic.

7.2 Scenario B ROI logic

Scenario B adds the Triplex package and should be presented as the highest-value productivity extension once PSC wants to strengthen the corrugator’s medium-term operating performance. The return logic here is associated with:

  • Higher long-term line capability versus a relocation-only approach.
  • Potential throughput improvement through a more capable corrugator architecture.
  • Better use of the relocated asset by complementing it with upgraded process modules rather than simply re-installing the line “as-is”.

7.3 Scenario C ROI logic

Scenario C adds AMR intralogistics and should be positioned as the plant efficiency and automation multiplier. The value case is not limited to labour substitution:

  • More disciplined internal material movement.
  • Reduced manual handling exposure and lower operator dependency on repetitive routes.
  • Potential reduction of handling-related waste and misrouting.
  • Creation of the future platform for traceable internal waste logistics.

Commercial guidance for ROI discussion with PSC

INGECART should avoid presenting one “hard” payback number unless PSC provides the operating data needed for a proper model: current productivity, labour structure, expected throughput, waste cost, shift pattern, maintenance cost of current internal transport assets, and target output ramp-up plan. Until then, the proposal should frame ROI as a phased industrial value roadmap rather than as a single over-simplified financial promise.

8. INGECART Recommendation to PSC

Recommended path for project award and execution

Based on the current state of the project, INGECART’s recommendation to PSC is to use the project structure as follows:

  1. Approve Scenario A as the core implementation platform, because it is the fastest route to bring the Visalia plant into operation with the correct relocation, utility, peripheral and reel logistics foundations.
  2. Evaluate Scenario B as the preferred next decision step, because it is the most coherent route if PSC wants to combine plant activation with a stronger productivity platform and avoid postponing the Triplex performance benefits too far into the future.
  3. Plan Scenario C as the future intralogistics automation phase, to be deployed once the plant is stabilised and PSC wants to move from a relocated line to a more digitally orchestrated internal flow model.

In short, INGECART believes the project should be understood in two layers:

  • Immediate mission: get the plant producing, fast and safely, with the right industrial backbone.
  • Strategic mission: build the future productivity and automation roadmap in a way that minimises disruption to production once the plant is live.

8.1 Final executive message to PSC

The relocation project should not be viewed as a one-off mechanical move. It is the opportunity to build a future-ready corrugated production platform in Visalia. The recommended structure protects time-to-market today, while preserving a credible path toward higher throughput, better logistics discipline and deeper automation tomorrow.
