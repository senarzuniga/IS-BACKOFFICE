# SPOE Template Packages

This folder contains template package manifests for standard products.

- `sr1400_template.json`: operational template package.
- `ingetrans_template.json`: prepared (empty) package.
- `amr_intralogistics_template.json`: prepared (empty) package.
- `amr_wip_template.json`: prepared (empty) package.
- `plug_play_palletizer_template.json`: prepared (empty) package.
- `heavy_duty_palletizer_template.json`: prepared (empty) package.
